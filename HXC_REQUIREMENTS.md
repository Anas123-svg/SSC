# HXC Site Compliance Audit — implementation mapping

**Basis:** Tony Turner-supplied `HXC_Site_Compliance_Audit_Final Rev 0122.docx` (12 pages).

**Project fields (page 1):** Project Name; Date of Assessment; Assessor; Project Manager Met; Site Address; Assessment Type (Monthly / Follow-up / Other).

**Scoring rules (page 1):**
- Statuses C / MI / MA / N/A per item, no numeric per-item score.
- Professional judgement overall **section** score 0–10; auditor rationale recorded.
- Any MI / MA requires a corrective action reference.
- Evidence note or appendix reference recorded.
- Overall % = average of applicable sections × 10; excluded N/A sections not counted.
- Rating key: 9–10 Excellent; 7–8 Good; 5–6 Improvement required; 3–4 Unsatisfactory; 0–2 Immediate intervention.

**Audit Summary (page 8):** section score, key concern/strength, number of open actions, total compliance, overall rating, key positives, and priority concerns. The portal currently calculates section average percentage and presents an indicative band based on the rating key.

**Corrective Action Tracker (page 9):** ref; finding/required action; priority; responsible person; target date; close-out date; verified by.

**Declaration and Close-Out (pages 9–10):** assessor and project manager signatures; report date; next review/follow-up. Current prototype uses typed acknowledgement only.

**Appendix A (pages 10–12):** supporting information and photographic references by audit item; 20 preprinted example slots in the DOCX. The web system uses a dynamic appendix without an artificial limit of 20 photos.
